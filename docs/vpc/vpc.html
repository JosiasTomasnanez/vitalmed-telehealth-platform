🏗️ Topología de VPC Multi-AZ aislada por Cuenta-País

Estrategia de 3 capas lógicas distribuidas en 2 Zonas de Disponibilidad (us-east-1a / us-east-1b) para alta disponibilidad y cumplimiento estricto de privacidad.

VPC País (Ej: VPC-Argentina 10.0.0.0/16)
1. Capa Pública IGW Route

Punto de entrada exclusivo. Contiene el Application Load Balancer (ALB) expuesto y los NAT Gateways redundantes.

AZ-a: 10.0.1.0/24 (Public)
AZ-b: 10.0.11.0/24 (Public)
2. Capa Privada NAT / Endpoints

Aloja las tareas de ECS Fargate (microservicios de Turnos, HCE, Facturación). No aceptan tráfico directo desde internet.

AZ-a: 10.0.2.0/24 (Private)
AZ-b: 10.0.12.0/24 (Private)
3. Capa Aislada Sin Salida a Internet

Bases de Datos e In-Memory Cache. Sin rutas hacia NAT Gateway ni Internet Gateway bajo ninguna circunstancia.

AZ-a: 10.0.3.0/24 (Isolated DB)
AZ-b: 10.0.13.0/24 (Isolated DB)

🔀 Estrategia de Salida a Internet y VPC Endpoints (Privatelink)

Optimizando seguridad y costos operacionales mediante tráfico interno en la red de AWS.

🛡️ NAT Gateways (Multi-AZ)

Ubicados en las subredes públicas de cada AZ. Permiten a las tareas ECS Fargate realizar llamadas salientes hacia APIs de terceros (ej. pasarelas de pago o sistemas de aseguradoras) sin quedar expuestas a conexiones entrantes.

⚡ VPC Interface & Gateway Endpoints

Para evitar que el tráfico a servicios gestionados pase por internet o NAT Gateway (ahorrando costos de datos), se configuran Endpoints privados para:

  • S3 (Gateway Endpoint)
  • ECR (Interface Endpoint para pull de imágenes Docker)
  • Secrets Manager & CloudWatch Logs

🌍 Enrutamiento Multi-País Bajo un Único Dominio

Estrategia para ofrecer localización por país (moneda, precios, features) utilizando Amazon Route 53 y CloudFront.

1. Geo-Location Routing

Route 53 detecta la IP del paciente/médico y resuelve a la CDN/ALB de su país de origen automáticos.

2. Ruteo por Path de URL

CloudFront o el ALB derivan el tráfico según la ruta: /ar/api/..., /cl/api/...

3. Aislamiento Backend

Cada petición termina en la VPC aislada del país correspondiente, garantizando soberanía de datos.
